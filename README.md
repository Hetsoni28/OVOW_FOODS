# OVOW FOODS

Premium vegetarian food website starter.

Stack: Next.js + TypeScript + Tailwind CSS + Framer Motion + Lucide React + Sanity-ready architecture.

Run:
1. npm install
2. npm run dev
3. open http://localhost:3000

Replace placeholder WhatsApp/phone numbers and media before production. Connect Sanity for products, gallery, reviews and bulk-order workflows.
